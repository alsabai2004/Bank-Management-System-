# 🛡️ منصة أدوات الأمن السيبراني (Cybersecurity Tools Hub)

منصة ويب متكاملة لإدارة وتوثيق أدوات الأمن السيبراني واختبار الاختراق، تم تطويرها بواسطة فريق هندسة الشبكات والأمن السيبراني - جامعة تعز. تستخدم المنصة تقنيات الواجهة الأمامية (HTML, CSS, JavaScript) والتخزين المحلي للمتصفح (LocalStorage).

---

## 📋 نظرة عامة

منصة أدوات الأمن السيبراني هي تطبيق ويب متكامل يسمح للمستخدمين بـ:

- 📝 إضافة أدوات سيبرانية جديدة مع تفاصيلها (الاسم، التصنيف، الوصف، أمر التشغيل).
- 📋 عرض جميع الأدوات المسجلة في كروت تفاعلية.
- 🗑️ حذف الأدوات من التخزين المحلي.
- 📱 تصميم متجاوب يعمل على جميع الأجهزة.
- 💾 تخزين البيانات محلياً في المتصفح باستخدام LocalStorage.

---

## ✨ الميزات الرئيسية

- 🔐 **واجهة احترافية**: تصميم داكن يليق بمجال الأمن السيبراني.
- ➕ **إضافة أداة**: نموذج متكامل لإضافة أدوات جديدة مع التحقق من صحة البيانات.
- 📋 **عرض الأدوات**: عرض جميع الأدوات المسجلة في كروت منسقة.
- 🗑️ **حذف أداة**: حذف الأدوات من التخزين المحلي بضغطة زر.
- 📱 **تصميم متجاوب**: يعمل بشكل مثالي على جميع أحجام الشاشات.
- 💾 **تخزين محلي**: استخدام LocalStorage لحفظ البيانات بشكل دائم.

---

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| **HTML5** | هيكل الصفحات وتنظيم المحتوى الدلالي |

## 📖 دليل الاستخدام

### 1️⃣ الصفحة الرئيسية (index.html)

- ترحيب بالمستخدم مع عرض شعار المنصة.
- أزرار للانتقال إلى صفحات "استعراض الأدوات" و "إضافة أداة".
- شريط تنقل علوي للتنقل بين جميع الصفحات.

#### مثال:
```

🛡️ CyberTools Hub
مرحباً بكم في منصة أدوات الأمن السيبراني
مرجعك البرمجي الشامل لإدارة وتوثيق أدوات الشبكات واختبار الاختراق

[استعراض الأدوات الحالية] [إضافة أداة جديدة]

```

---

### 2️⃣ إضافة أداة جديدة (add-tool.html)

1. انتقل إلى صفحة **"إضافة أداة"**.
2. املأ جميع الحقول المطلوبة:
   - **اسم الأداة**: مثال: Nmap
   - **تصنيف الأداة**: اختر من القائمة المنسدلة
   - **وصف الأداة**: شرح موجز عن وظيفة الأداة
   - **أمر التشغيل الأساسي**: مثال: nmap -sV
3. انقر على زر **"حفظ الأداة في الـ LocalStorage 💾"**.
4. ستظهر رسالة تأكيد بحفظ الأداة بنجاح.

#### مثال:
```

إضافة أداة سيبرانية جديدة
قم بتعبئة بيانات الأداة لتخزينها في المرجع العام للمنصة

اسم الأداة: Nmap
تصنيف الأداة: جمع المعلومات (Reconnaissance)
وصف الأداة: أداة مفتوحة المصدر لاستكشاف الشبكات وفحص المنافذ
أمر التشغيل الأساسي: nmap -sV 192.168.1.1

✅ تم حفظ الأداة (Nmap) بنجاح!

```

---

### 3️⃣ استعراض الأدوات (tools.html)

- عرض جميع الأدوات المسجلة في كروت منسقة.
- كل كرت يحتوي على:
  - اسم الأداة.
  - تصنيف الأداة (مع شارة ملونة).
  - وصف الأداة.
  - أمر التشغيل الأساسي (مع تنسيق خاص).
  - زر حذف الأداة.
- إذا لم توجد أدوات، تظهر رسالة "لا توجد أدوات مسجلة حالياً".

#### مثال:
```

الأدوات السيبرانية المسجلة
قائمة بجميع الأدوات المخزنة محلياً في المتصفح

┌─────────────────────────────────────────────┐
│ Nmap                    [جمع المعلومات]    │
│ أداة مفتوحة المصدر لاستكشاف الشبكات وفحص   │
│ المنافذ                                     │
│ $ nmap -sV 192.168.1.1                      │
│ [🗑️ حذف الأداة]                             │
└─────────────────────────────────────────────┘

```

🚀 كيفية التشغيل

المتطلبات

· متصفح ويب حديث (يدعم LocalStorage و ES6).
· لا يتطلب خادم ويب للعمل.

الخطوات

1. تحميل الملفات:
   قم بتحميل جميع الملفات في مجلد واحد.
2. فتح المتصفح:
   افتح ملف index.html في متصفحك.
3. بدء الاستخدام:
   · استخدم شريط التنقل للتنقل بين الصفحات.
   · أضف أدوات جديدة، اعرضها، أو احذفها.

📝 ملاحظات للمطورين

· جميع البيانات تُخزن في localStorage تحت المفتاح "cyberTools".
· كل أداة لها معرف فريد (id) يتم إنشاؤه باستخدام Date.now().
· الصفحات تشترك في ملف script.js واحد وملف style.css واحد.
· التحقق من البيانات: يتم التحقق من تعبئة جميع الحقول قبل الحفظ.
· التصميم: يستخدم Flexbox و Grid لتوزيع العناصر بشكل مرن.

🔧 التخصيص والتطوير

إضافة حقول جديدة للأداة

1. أضف الحقل الجديد في صفحة add-tool.html.
2. قم بتعديل كائن newTool في script.js.
3. أضف الحقل الجديد في دالة displayTools() لعرضه.

تغيير ألوان التصميم

يمكنك تغيير الألوان في ملف style.css:

```css
:root {
    --primary: #3b82f6;
    --secondary: #10b981;
    --danger: #ef4444;
    --dark: #0f172a;
    --medium: #1e293b;
}
```

إضافة ميزات جديدة

1. بحث وتصفية: إضافة شريط بحث لتصفية الأدوات.
2. تعديل أداة: إضافة زر تعديل لتحديث بيانات الأداة.
3. تصدير البيانات: تصدير الأدوات إلى ملف JSON.
4. إحصائيات: عرض عدد الأدوات حسب التصنيف
